# Plan

Tasks for the agent loop. One row = one task = one PR. Add rows by hand or with `/pitwall:queue <task in words>` (the row lands with the task's PR). Task PRs never tick their row: the loop ticks rows and writes the Progress log in one docs PR after the task PRs merge. Ticked rows stay as history.

Phase 0 (scaffold, content, tokens, CI, next-intl cookie i18n like the mkp repo — no locale in the URL) is done. Phase 1 rows touch disjoint files so they can run in parallel. Read `CLAUDE.md` and `DESIGN.md` first: content in `src/content/`, colours from tokens, `Reveal` for motion, reduced motion respected, 360px with no horizontal scroll.

Phase 1 (rows P1-*) shipped the "teacher's journal" look. **Phase 2 (rows P2-*) rebuilds the whole look as "the teacher's notebook"** — grid-paper page, lined sheets taped on, sticky notes, polaroids, crayon cut-outs, the teacher's pen marks — per `DESIGN.md` (reference: Mr. Panda's Paper Portfolio; owner chose prototype "A" on 2026-10-24). Blue **text** and text-carrying buttons use `ink-blue` (AA), never `crayon-blue` (DESIGN.md colour tokens). Content, i18n, routes and behaviour (lightbox, nav, language switch, pause pill, SEO) stay; this phase changes the look. P2-01 lands first: every other P2 row builds on its primitives.

**Phase 3 (rows P3-*) adds the client's second batch of photos** (sent 2026-10-24, kept out of git in `new/`): certificates, the teacher making teaching media, and more activities. The lead prepares every image before a row starts — resized to ≤ 1600 px, EXIF/GPS stripped, every pupil's face blurred and checked by eye — and the row only copies the prepared files into `public/images/`. Never copy anything from `new/` directly. The three rows touch disjoint files; in `translation.json` each adds its own block (`certificates` after `education`, `teachingMedia` after `skills`, `activities.*` entries for P3-03) so the merges stay clean. The header nav stays as it is (new sections are reachable by scrolling).
